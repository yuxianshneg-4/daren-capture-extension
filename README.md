# 达人信息抓取录入助手

在抖音精选联盟的达人详情页，自动识别达人数据并一键录入到你**自己的**飞书多维表格。

**它能自动抓 16 项信息**：达人昵称、平台、粉丝量、粉丝量级、省份、达人等级、月GMV、平均单价、商品数、店铺数、一级类目、主推产品、抖音号（账号ID）、微信号、主页链接、账号简介，外加自动填当天的建联日期。

**三个省心点**：
- 数据直连飞书官方接口写进你自己的表，**不经过任何第三方服务器**
- 打开达人页不会自动动你页面；你判断达人合适后点一下，插件自动模拟点击（二维码弹窗抓抖音号 → 主页按钮抓链接 → 微信号眼睛显明文 → 轮播概览/场景分析/粉丝分析/评价详情/带货分析全部标签页），约 12 秒抓完
- 提交前可核对修改，按主页链接自动查重，已有记录可选择"更新"或"仍然新建"

| 步骤 | 耗时 | 做什么 |

## A. 安装插件（Chrome / Edge 通用）

1. 下载本仓库 Release 里的 zip，解压到一个**固定位置**（之后不要删除或移动该文件夹，浏览器会一直引用它）
2. 打开 Chrome，在地址栏输入 `chrome://extensions` 后回车
3. 打开页面**右上角**的「开发者模式」开关
4. 点左上角「**加载已解压的扩展程序**」，选中解压出来的 `extension` 文件夹
5. 点浏览器右上角的拼图图标 🧩，把「达人信息抓取录入助手」点📌固定，方便随时打开面板

> 装好后先别急，接着完成 B 部分的飞书配置才能用。

---

## B. 飞书配置（照抄即可，只需做一次）

### B1. 建一张多维表格并照抄这 17 列

在飞书里新建一个多维表格（可以叫「达人数据库」），在第一个数据表里**按顺序建这 17 列**（列名必须一字不差，插件按名字匹配）：

| # | 列名 | 字段类型 | 选项值 / 说明 |
|---|------|----------|---------------|
| 1 | 达人昵称 | 文本 | 必填，抓不到时插件不会提交 |
| 2 | 平台 | 单选 | 加一个选项：`抖音` |
| 3 | 粉丝量 | 数字 | 抓"982"这类原数，"98.2万"自动换算成 982000 |
| 4 | 粉丝量级 | 单选 | `1万以下`、`1-5万`、`5-10万`、`10-50万`、`50万以上`（插件按粉丝数自动判断，选项名必须一致） |
| 5 | 省份 | 单选 | 按需添加省份，如 `河南`、`广东`（页面抓到"河南·商丘"会自动匹配前缀） |
| 6 | 达人等级 | 单选 | `Lv1` ~ `Lv5`（页面识别不到等级徽章时默认填 Lv1） |
| 7 | 月GMV | 单选 | 区间文本，**需与页面展示的区间一致**，如 `0-250`、`250-500`、`500-1000` 等 |
| 8 | 平均单价 | 数字 | |
| 9 | 商品数 | 数字 | 取"带货分析"页的带货商品数 |
| 10 | 店铺数 | 数字 | 取"带货分析"页的合作店铺数 |
| 11 | 一级类目 | 多选 | 按你的业务添加类目名，如 `母婴宠物`、`服饰鞋包`（只有与选项名一致的页面类目会被选中） |
| 12 | 主推产品 | 多选 | 同上，按需添加 |
| 13 | 账号ID | 文本 | 存抖音号（自动点二维码弹窗抓取） |
| 14 | 微信号 | 文本 | 自动点眼睛图标显明文后抓取 |
| 15 | 主页链接 | 文本 | 查重的唯一依据 |
| 16 | 账号详细 | 文本 | 存达人简介 |
| 17 | 建联日期 | 日期 | 插件自动填提交当天的日期 |

### B2. 创建飞书应用并授权

1. 打开 [飞书开放平台](https://open.feishu.cn) → 右上角进入「开发者后台」
2. 点「创建企业自建应用」，名字随意（如「达人录入」），创建成功后进入应用页面
3. 左侧「权限管理」→ 搜索 `bitable` → 开通「**查看、评论、编辑和管理多维表格**」这一项
4. 左侧「版本管理与发布」→ 创建版本 → 设置可用范围（选你自己或全员）→ 发布（自建应用一般秒过）
5. 左侧「凭证与基础信息」→ 复制 **App ID** 和 **App Secret**（Secret 只显示一次，保存好）

### B3. 取多维表格的两个参数

打开你 B1 建的多维表格，看浏览器地址栏：

```
https://xxx.feishu.cn/base/GlClbxxxxxxxxxxxx?table=tblUxxxxxxxxxxxx&view=vewxxxx
                              ↑ base token            ↑ 表 ID
```

- `/base/` 后面那串（到 `?` 为止）= **Base Token**
- `table=` 后面那串（到 `&` 为止）= **表 ID**

### B4. 填进插件

1. 在精选联盟达人详情页打开插件侧边面板（或右键扩展图标 → 选项）
2. 依次填入 App ID、App Secret、Base Token、表 ID → 保存
3. 面板上的下拉框和类目标签会自动加载你表格里的选项，出现即代表连通成功

## C. 日常使用（3 次点击）

1. 打开精选联盟的达人详情页 → 面板会静默识别页面上直接可见的信息
2. **你自己判断这个达人行不行**：
   - 不合适 → 什么都不用点，直接看下一个，不会产生任何数据
   - 合适 → 点「**开始捕获录入**」，等约 12 秒自动抓完全部标签页
3. 核对面板字段（一级类目、主推产品等需要人工判断的项手动点选）→ 点「**确认录入**」写入飞书

> 若表中已有同主页链接的达人，会弹窗问你是「更新此记录」还是「仍然新建」。

## 常见问题

| 现象 | 解决 |
|------|------|
| 提示"还没配置飞书凭证" | 右键扩展图标 → 选项，检查四项是否填全 |
| 微信号偶尔为空 | 手动点一下页面上微信号旁的眼睛图标 → 点「重新识别」 |
| 某些字段没识别 | 手动切换一下标签页再点「重新识别」；多次失败可能是页面改版，等更新 |
| 抖音号没抓到 | 确认达人资料区已加载；插件会自动重试多个图标，仍失败就手动点二维码弹窗后点「重新识别」 |
| 提交报飞书接口错误 | 对照报错里的列名检查表格列名是否一致；检查应用权限是否发布生效 |
| 一级类目/主推产品不自动选中 | 表格里的选项名要和页面上的类目名完全一致，补齐选项即可 |

## 项目结构与工作原理（想改的人看）

```
extension/
├── manifest.json    # MV3 配置：权限、双内容脚本声明（含 MAIN world 补丁）
├── patch_open.js    # 注入页面真实环境的 window.open 补丁：点"达人主页"不弹新标签，链接经事件+DOM属性双通道回传
├── scrapers.js      # 识别规则：锚点文本定位 + 正则提取 + 与表格选项匹配
├── content.js       # 侧边面板 UI：两段式录入、字段可改、查重确认、自动模拟点击序列
├── background.js    # 直连飞书 OpenAPI：token 缓存、读字段选项、查重/新增/更新
└── options.*        # 凭证配置页（存 chrome.storage.sync，本地保存）
```

改识别规则一般只动 `scrapers.js`；页面改版导致点击失效时调 `content.js` 里的 `findQrCandidates` / `clickTab`。
